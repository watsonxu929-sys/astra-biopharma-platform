# v0.5A 登录、角色权限、隐私保护与操作审计

## 目标

v0.5A 为产业情报、Q-BAY 会员数据、审核流程和后续多人协作增加最小可用的安全边界。

系统新增：

- 首次运行管理员初始化；
- 用户名和密码登录；
- 管理员、业务运营、数据审核、只读查看四种角色；
- 会员联系方式按权限显示；
- 写入、审核、用户管理权限分离；
- 登录失败临时锁定；
- 密码重置后旧会话失效；
- 内部写操作和登录行为审计。

## 首次使用

执行：

```bat
migrate_all_windows.bat
run_windows.bat
```

首次进入系统时会自动跳转：

```text
http://127.0.0.1:8000/setup/admin
```

创建首位管理员后即可进入系统。

## 角色说明

### 系统管理员 admin

- 管理用户和角色；
- 查看审计日志；
- 执行所有业务操作；
- 查看会员申请联系方式；
- 数据导出。

### 业务运营 operator

- 维护企业、人物、项目、线索和行动；
- 管理 Q-BAY 会员和供需；
- 执行情报监测；
- 使用推荐中心；
- 查看内部敏感联系方式；
- 不能批准数据审核事项或管理用户。

### 数据审核 reviewer

- 查看内部数据；
- 处理审核队列和监测更新建议；
- 使用推荐中心；
- 查看审核所需敏感联系方式；
- 不能直接修改普通业务数据或管理用户。

### 只读查看 viewer

- 查看内部页面；
- 不能提交写操作；
- 不能查看会员联系方式；
- 不能导出会员数据。

## 用户管理

管理员入口：

```text
http://127.0.0.1:8000/admin/users
```

可执行：

- 创建用户；
- 修改显示姓名；
- 修改角色；
- 停用或恢复账号；
- 重置临时密码。

新建用户和重置密码后，用户下次登录必须修改密码。

系统不允许停用或降级最后一个有效管理员。

## 操作审计

入口：

```text
http://127.0.0.1:8000/admin/audit
```

记录范围包括：

- 登录成功与失败；
- 退出登录；
- 用户创建、角色修改和密码重置；
- 内部 POST、PUT、PATCH、DELETE 操作；
- 操作者、路径、目标、状态码和时间。

审计日志不记录密码、表单全文或完整敏感联系方式。

## 隐私规则

- `/club/apply` 继续作为公开会员申请入口；
- 其他内部页面必须登录；
- 会员申请联系方式仅授权角色可见；
- 只读角色无法导出会员 CSV；
- 用户停用、角色变化和密码变化会使旧会话失效；
- Cookie 默认使用 HttpOnly 和 SameSite=Lax；
- 线上 HTTPS 部署时应设置 `APP_COOKIE_SECURE=1`。

## 环境变量

```text
APP_SESSION_SECRET=自定义长随机字符串
APP_COOKIE_SECURE=1
APP_AUTH_DISABLED=1
```

说明：

- `APP_SESSION_SECRET`：线上部署应显式设置；本地缺省时系统会在 `data/.session_secret` 自动生成。
- `APP_COOKIE_SECURE=1`：仅在 HTTPS 环境启用。
- `APP_AUTH_DISABLED=1`：仅供自动化验证或紧急本地诊断，不应在正常运行或线上部署中使用。
