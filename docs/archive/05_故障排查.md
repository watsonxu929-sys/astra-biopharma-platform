# 故障排查

## `/review/intake/health` 显示 404

`app/main.py` 未接入路由，或修改了错误的项目副本。运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -c "from app.main import app; print([r.path for r in app.routes if r.path.startswith('/review/intake')])"
```

应至少看到 `/review/intake` 和 `/review/intake/health`。

## 页面显示 500

先运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\verify_v04c1.py
```

然后查看后端窗口最后一段红色报错。

## 从现有表导入后没有审核任务

该表记录可能只有纯文本，没有可识别的结构化 `fields` 或 `relations`。这是安全设计：记录会进入来源收件箱并显示 `needs_structuring`，不会自动从文字中编造字段。

## 审核通过后正式事实库仍为空

检查审核时是否同时选择了“定为事实”。仅“通过”但属性仍为推测或待判定时，不会同步。完成审核后还需在 `/review/intake` 点击“同步已通过记录”。

## 业务表没有更新

依次检查：

1. 映射是否启用；
2. 主体类型和字段名是否与候选完全一致；
3. 候选是否有 subject_id；
4. 目标表中是否存在相同 ID；
5. “同步日志”是否显示 skipped 或 failed。

## `.cmd` 双击闪退

本补丁中的 `.cmd` 已使用 CRLF 换行并带 `pause`。仍有问题时，直接在 VS Code 终端运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\migrate_v04c1.py
.\.venv\Scripts\python.exe -X utf8 scripts\verify_v04c1.py
```
