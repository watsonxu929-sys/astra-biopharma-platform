# v0.4C 手动替换步骤

## 一、先备份

1. 关闭正在运行的前端和后端窗口。
2. 复制整个项目文件夹，或至少复制 `data\app.db`。
3. 不要删除 `.venv`、`app`、`data`、`reference_documents`、`scripts`。

迁移脚本运行时还会自动把数据库备份到：

`data\backups\app_before_v04c_日期_时间.db`

## 二、复制文件

将补丁包里的文件复制到项目根目录，对应关系如下：

| 补丁包文件 | 复制到项目 |
|---|---|
| `app\v04c_review.py` | `你的项目\app\v04c_review.py` |
| `app\templates\v04c_review_queue.html` | `你的项目\app\templates\v04c_review_queue.html` |
| `scripts\migrate_v04c.py` | `你的项目\scripts\migrate_v04c.py` |
| `scripts\verify_v04c.py` | `你的项目\scripts\verify_v04c.py` |
| `scripts\seed_v04c_demo.py` | `你的项目\scripts\seed_v04c_demo.py` |
| 三个 `.bat` 文件 | 项目根目录 |

同名目录直接合并，不要删除其中原有文件。

## 三、修改主入口

打开现有 FastAPI 主入口文件，通常是 `app\main.py`，按 `patches\main_py_必须追加.txt` 的内容追加两行。

第一行是导入：

```python
from app.v04c_review import router as v04c_review_router
```

第二行放在 `app = FastAPI(...)` 之后：

```python
app.include_router(v04c_review_router)
```

## 四、迁移数据库

双击：

`migrate_v04c_windows.bat`

看到 `[OK] v0.4C 数据库迁移完成` 后再关闭窗口。

## 五、自检

双击：

`verify_v04c_windows.bat`

必须看到：

`[SUCCESS] v0.4C 自检全部通过。`

## 六、启动系统

继续使用原来的 `run_windows.bat` 启动项目，然后访问：

`http://127.0.0.1:8000/review`

先不要运行演示数据。只有页面为空、希望观察完整效果时，才双击 `seed_v04c_demo_windows.bat`。
