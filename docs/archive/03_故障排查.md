# v0.4C 故障排查

## 1. 启动时报 `ModuleNotFoundError: No module named 'app.v04c_review'`

检查文件是否位于：

`项目根目录\app\v04c_review.py`

不要放进 `_v04c_manual_patch\app` 后就直接启动；必须复制进正式 `app` 目录。

## 2. 启动时报 `Form data requires "python-multipart"`

项目原 requirements 已包含 `python-multipart`。在项目根目录执行：

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 3. `/review` 显示 404

通常是主入口没有挂载路由。检查 `app\main.py` 是否同时存在：

```python
from app.v04c_review import router as v04c_review_router
app.include_router(v04c_review_router)
```

并确认第二行位于 `app = FastAPI(...)` 之后。

## 4. 页面报 `TemplateNotFound`

检查模板路径：

`项目根目录\app\templates\v04c_review_queue.html`

## 5. 数据库报 `database is locked`

1. 关闭重复启动的后端窗口。
2. 不要同时双击两次 `run_windows.bat`。
3. 重新运行迁移脚本。

模块已启用 WAL、30 秒等待和事务回滚，一般不会因短暂并发损坏数据库。

## 6. 主入口使用的不是 `app\main.py`

查看原 `run_windows.bat` 中类似：

```bat
uvicorn app.main:app
```

冒号前面的文件就是主入口模块。例：`uvicorn app.web:app` 对应 `app\web.py`。

## 7. 如何回退

1. 关闭系统。
2. 从 `app\main.py` 删除 v0.4C 的 import 和 `include_router` 两行。
3. 删除新增文件 `app\v04c_review.py` 与模板。
4. v0.4C 数据表以 `v04c_` 开头，不影响原表；无需立即删除。
5. 若数据库异常，可用 `data\backups\app_before_v04c_*.db` 覆盖恢复。
