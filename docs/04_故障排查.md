# v0.4D-B 故障排查

## 启动时报缺少 v0.4D-A

错误类似：

```text
v0.4D-B requires v0.4D-A
```

确认存在：

```text
app/v04d_structuring.py
```

并先运行 v0.4D-A 迁移和自检。

## `/review/prestructure` 显示 404

检查 `app/main.py` 是否存在：

```python
from app.v04db_prestructure import router as v04db_prestructure_router
app.include_router(v04db_prestructure_router)
```

保存后重新启动后端。

## 页面没有来源

这里只显示状态为：

```text
needs_structuring
```

的来源。先在 `/review/intake` 接入纯文本来源，或运行演示脚本。

## 提取结果为零

可能原因：

- 文本不包含当前规则支持的字段；
- 文本过短；
- 规则被停用；
- 正则表达式与实际写法不匹配。

可以调整规则后点击“重新提取”，或者回到 `/review/structure` 人工录入。

## 接受候选失败

常见原因：

- 对应 v0.4D-A 任务已经提交复核或送审，不再允许编辑；
- 字段候选缺少主体名称；
- 关系候选缺少左右主体；
- 事件候选缺少名称或摘要。

打开对应结构化任务检查状态。

## 批量接受高置信度后仍有候选

中、低置信度候选不会自动接受，必须逐条确认。

## `.cmd` 闪退

本包使用 CRLF 并保留窗口。仍有问题时，在 VS Code 终端运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\migrate_v04db.py
.\.venv\Scripts\python.exe -X utf8 scripts\verify_v04db.py
```

日志位于：

```text

```
