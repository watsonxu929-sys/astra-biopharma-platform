# 项目宪章

## 版本

PGF v2.0

## 项目使命

建立生物医药产业领域最专业的产业情报系统，促进产业资源对接与业务协同。

## 项目愿景

成为生物医药产业从业者的核心工作平台，提供完整的产业情报、主体关系、资源匹配和商务协作能力。

## 项目定位

产业情报系统 = 产业社交网络 + 产业情报平台 + 资源交易市场 + 商务协作工具

## 成功标准

1. 核心业务模块稳定运行
2. 数据质量达到生产标准
3. 权限控制有效且安全
4. 用户体验符合专业要求
5. 系统可扩展性良好

## 项目边界

本系统专注于生物医药产业，不涉及：

- 医疗健康服务
- 药品销售
- 临床试验管理
- 医疗设备运维

## 六大核心业务

1. **情报中心** - 产业情报收集、整理、分析、推送
2. **主体档案** - 机构、人物、项目、资源、事件的完整档案
3. **关系网络** - 产业关系图谱、合作关系管理
4. **资源市场** - 产业资源发布、需求匹配、交易撮合
5. **商务协作** - 合作机会、商机跟进、任务管理
6. **AI赋能** - 智能推荐、自动情报、知识图谱

## 明确说明

- **不是CRM**：不专注于客户关系管理
- **不是ERP**：不专注于企业资源计划
- **不是OA**：不专注于办公自动化
- **不是普通知识库**：不是简单的文档管理系统
