## 三、核心点击链路

### 链路一：情报
- 工作台 → 情报中心 → 采集与数据源 → 今日情报 → 情报详情 → 审核发布 ✅

### 链路二：产业关系
- 产业关系 → 人物与机构 → 详情 → 关系网络 → 连接路径查询 → 人脉推荐 ✅

### 链路三：俱乐部
- Q-BAY俱乐部 → 会员 → 活动 → 报名 → 审核 → 签到 → 反馈 → 供需与匹配 ✅

### 链路四：业务协同
- 业务协同 → 线索 → 人工确认 → 转化合作机会 → 添加参与者 → 添加跟进 → 创建任务 → 创建会议 ✅

## 十二、启动方式

### 正式环境
```bat
run_windows.bat
```
- 使用 data/app.db
- 默认显示运行模式和调度器状态
- 默认地址：http://localhost:8000/

### 验收环境
```bat
run_acceptance_windows.bat
```
- 使用 data/acceptance/t5_1_mvp.db
- 显示"验收环境"标识
- 地址：http://localhost:8001/

## 十三、回滚方式

1. **代码回滚**：`git checkout checkpoint-trae-usable-mvp-final`
2. **数据库回滚**：正式库未修改，无需回滚
3. **验收库重建**：运行 `scripts/create_acceptance_db.py`
