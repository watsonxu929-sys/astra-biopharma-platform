v0.5F Multi-source Collection Patch Manifest

- Add controlled public-source collection, URL discovery, snapshots, deduplication, queueing and local worker execution.

Install:
1. Back up the existing project and database.
2. Overwrite files with this patch.
3. Run migrate_all_windows.bat.
4. Run verify_all_windows.bat.
5. Run run_windows.bat.

Manual acceptance:
- Open http://127.0.0.1:8000/collection.
- Create a public RSS or web page source.
- Create a job and run the collection worker.
- Confirm collection items enter the queue.
- Confirm duplicate content is not queued repeatedly.
- Confirm formal subject records are not changed automatically.

Rollback:
- Restore previous files.
- Restore the database backup from data/backups/ if a real migration was run.
