# v0.5A 覆盖补丁安装与验收

## 安装前

1. 关闭正在运行的后端窗口。
2. 复制整个项目目录作为手工备份。
3. 不要删除 `data/app.db`。

## 覆盖

将补丁 ZIP 解压到项目根目录，出现同名文件时选择“替换目标中的文件”。

补丁不包含 `data/app.db`、日志、虚拟环境或数据库备份。

## 迁移

双击：

```bat
migrate_all_windows.bat
```

迁移前会自动备份数据库到：

```text
data\backups\app_before_migrate_all_时间戳.db
```

## 验证

双击：

```bat
verify_all_windows.bat
```

验证日志：

```text
logs\verify_all_latest.log
```

专项验证可运行：

```bat
tools\windows\archive\v05a\verify_v05a_windows.bat
```

## 首次启动

双击：

```bat
run_windows.bat
```

首次进入系统会自动打开管理员初始化页：

```text
http://127.0.0.1:8000/setup/admin
```

创建首位管理员后，系统内部页面将要求登录。

公开会员申请页保持可用：

```text
http://127.0.0.1:8000/club/apply
```

## 人工验收

1. 管理员可进入 `/admin/users` 和 `/admin/audit`。
2. 创建一个“只读查看”账号。
3. 使用只读账号登录后，可以查看企业列表，但不能新增、编辑或审核。
4. 只读账号不能进入会员申请审核页，也不能导出会员 CSV。
5. 业务运营账号可以维护主体、线索和俱乐部，但不能批准数据审核事项。
6. 数据审核账号可以处理审核队列，但不能编辑普通业务数据。
7. 管理员重置用户密码后，该用户旧会话失效，并在下次登录时强制修改密码。

## 回滚

代码回滚：恢复安装前复制的整个项目目录。

数据库回滚：关闭系统后，将迁移前备份复制回 `data/app.db`。回滚前先额外备份当前数据库，避免丢失安装后产生的新数据。
