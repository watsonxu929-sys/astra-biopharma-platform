# 03 User Guide

## 原始情报

使用 `/intelligence/new` 录入标题、来源链接、来源类型和正文。原始情报不会自动成为正式事实，需要经过结构化接入和审核。

## 业务对象管理

系统支持管理：

- 主体 `/organizations`
- 人物 `/people`
- 项目 `/projects`
- 资源 `/resources`
- 事件 `/events`
- 关系 `/relations`
- 行动 `/actions`

这些页面保留原有 CRUD 能力。v0.4C-1 默认只写正式事实库，不直接改写业务表。

## 数据审核

打开 `/review` 可以查看待审核、审核中、暂缓、已通过、已驳回的记录。审核时应填写说明；通过时可以填写最终采用值，并明确选择事实、推测或待判定。

## 数据接入

打开 `/review/intake` 可以：

- 粘贴结构化 JSON。
- 从现有原始情报或导入表读取数据。
- 查看批次、来源、候选和正式事实。
- 同步已审核通过且定为事实的记录。
- 手动建立业务表映射。

## 基本安全原则

- 推测不会直接进入正式事实库。
- 待确认关联必须人工确认后才能进入正式关系库。
- 业务表同步默认关闭，必须手动建立并启用映射。
- 不同值会生成冲突任务，不覆盖旧值。
