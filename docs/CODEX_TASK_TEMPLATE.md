## 使用示例

### 任务名称
实现会员申请提交功能

### 任务目标
完成会员申请表单的后端处理逻辑，包括数据验证和数据库写入

### 允许修改
- app/services/club_operations_service.py
- app/api/v1/club.py
- app/v04f_operations.py

### 禁止修改
- data/app.db
- app/templates/
- 任何迁移文件

### 完成标准
1. 表单数据能正确写入v04f_club_applications表
2. 表单验证逻辑完整
3. 返回正确的HTTP状态码
4. 不修改任何数据库结构

### 数据库保护
- 是否涉及数据库变更：否
- 是否为正式库变更：否
- 变更前是否备份：无需

### 额度限制
预计消耗5000 tokens

### 交付格式
代码变更 + 测试验证报告
