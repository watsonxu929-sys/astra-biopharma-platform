# v0.5B Q-BAY 会员智能采集、批量导入与头像管理

## 目标

v0.5B 将会员录入从逐项手填升级为：

```text
粘贴文字 / Word / Excel / CSV
→ 自动识别字段和多人记录
→ 生成独立会员草稿
→ 人工核对、重复识别和头像关联
→ 批量保存人物、机构、会员身份、供需与联系方式
```

系统不会未经人工确认直接把文件内容写入正式会员库，也不会自动合并同名人物。

## 入口

- 会员智能导入：`/club/import`
- 会员管理：`/club/members`
- Excel 模板：`/club/import/template.xlsx`
- 健康检查：`/v05b/health`

仅系统管理员和业务运营角色可使用会员导入与头像上传。

## 支持格式

- 粘贴文字：字段标签、制表符表格、CSV 风格文本、紧凑名单和单人简介。
- Word：`.docx` 段落、表格和内嵌图片。
- Excel：`.xlsx` 多工作表、常见中文/英文字段表头和锚定行图片。
- 旧 Excel：`.xls` 数据表格；图片不读取。
- CSV：UTF-8、GB18030、UTF-16 常见编码。
- 文本：`.txt`。

旧版 `.doc` 请先在 Word 中另存为 `.docx`。

单次限制：文件不超过 20MB，最多 300 条会员草稿，单张图片不超过 10MB。

## 自动识别字段

- 姓名、机构、职位
- 手机、邮箱、微信、联系偏好
- 城市、关注赛道、专业能力
- 可提供资源、合作需求、个人简介
- 推荐人、加入来源
- 会员等级、会员状态、负责人

字段识别不确定时会保留来源原文并显示核对提示。

## 保存闭环

确认保存后，系统按顺序处理：

1. 匹配或创建机构；
2. 复用已明确选择的人物，或创建新人物；
3. 建立人物—机构任职关系；
4. 创建 Q-BAY 会员身份；
5. 将联系方式写入独立隐私表；
6. 将需求与可提供资源写入会员供需；
7. 绑定人工确认的头像；
8. 保留导入任务、来源位置、原文和保存结果。

## 重复识别

系统重点检查：

- 手机号；
- 邮箱；
- 姓名与机构；
- 已存在的有效会员身份。

发现现有会员后默认跳过。用户可以人工选择：

- 跳过；
- 关联现有会员，只补充空白字段；
- 确认是不同人物，创建新人物和会员。

系统不会仅凭姓名相同自动合并人物。

## 头像功能

支持：

- 在导入草稿中上传 JPG、PNG、WEBP；
- 从 Word 内嵌图片提取候选；
- 从 Excel 锚定行图片提取候选；
- 从公开人物页或团队页提取图片候选并人工绑定；
- 在会员档案中上传或替换头像；
- 在会员档案和人物详情中展示头像。

系统不进行人脸识别。网页图片只作为候选，必须人工选择对应人物。照片来源、抓取页面和操作人会被保留。

## 隐私与安全

- 联系方式保存于 `v05b_member_contacts`，只对具备敏感信息权限的内部账号展示。
- 公共会员申请页不会展示会员列表或导入工作台。
- 临时上传文件在解析后删除，正式保存的头像存放于私有数据目录，通过受登录保护的路由读取。
- 网页读取拒绝本机和内网地址，避免 SSRF 风险。
- 审计中间件记录导入和头像上传操作，但不主动写入完整手机号、邮箱或微信内容。
