# v0.4D-B 功能与验收清单

## 一、来源提取

- [ ] `/review/prestructure` 可以打开。
- [ ] `needs_structuring` 来源能够单条提取。
- [ ] 可以勾选多条来源批量提取。
- [ ] 单条失败不会导致整个批次停止。
- [ ] 普通重复点击复用已有提取批次。
- [ ] “重新提取”会创建新批次。

## 二、自动候选

- [ ] 可以识别融资金额。
- [ ] 可以识别融资轮次。
- [ ] 可以识别临床阶段。
- [ ] 可以识别员工人数。
- [ ] 可以识别估值。
- [ ] 可以识别成立时间。
- [ ] 可以识别项目或药物代号。
- [ ] 可以生成关系候选。
- [ ] 可以生成事件候选。

## 三、证据与置信度

- [ ] 每条候选都有原文证据。
- [ ] 每条候选保存正文起止位置。
- [ ] 每条候选显示具体置信度。
- [ ] 每条候选显示高、中、低等级。
- [ ] 每条候选显示提取理由。
- [ ] 找不到证据的内容不会生成候选。

## 四、主体匹配

- [ ] 已有主体精确匹配时显示 `exact`。
- [ ] 模糊匹配时显示建议列表。
- [ ] 无匹配时显示 `new_subject`。
- [ ] 系统不会自动合并或新建正式主体。

## 五、人工确认

- [ ] 可以单条接受候选。
- [ ] 字段候选接受前可以修改主体ID、名称和值。
- [ ] 可以修改事实属性为事实、推测或待判定。
- [ ] 可以删除错误候选。
- [ ] 可以批量接受全部高置信度候选。
- [ ] 已接受候选不会重复生成结构化条目。

## 六、安全边界

- [ ] 自动候选只进入 v0.4D-A 草稿。
- [ ] 不直接进入 v0.4C 审核队列。
- [ ] 不直接写正式事实库。
- [ ] 不直接写正式关系库。
- [ ] 关系候选仍需人工确认。
- [ ] v0.4D-A 的“提交结构化复核”流程保持不变。

## 七、规则管理

- [ ] 可以启用或停用规则。
- [ ] 可以修改正则表达式。
- [ ] 无效正则不能保存。
- [ ] 可以调整优先级。
- [ ] 可以调整基础置信度。
- [ ] 规则修改只影响后续重新提取。
