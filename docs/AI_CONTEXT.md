# AI上下文固定说明

## 版本

PGF v2.0

## 系统唯一定位

```
产业社交网络 + 产业情报平台 + 资源交易市场 + 商务协作工具
```

### 产业社交网络

- 生物医药产业从业者之间的连接
- 机构与机构之间的关系网络
- 人物与机构的关联
- 产业活动与会员管理

### 产业情报平台

- 产业动态监控
- 政策法规跟踪
- 技术进展分析
- 市场情报收集

### 资源交易市场

- 产业资源发布与搜索
- 需求匹配
- 合作机会撮合
- 资源交易管理

### 商务协作工具

- 商机跟进
- 任务管理
- 会议安排
- 协作沟通

## AI Agent参考

任何AI Agent（Codex、Trae、WorkBuddy、Claude、Cursor等）在执行任务时，必须以上述定位作为唯一上下文。

## 禁止偏离

- 不得将系统视为CRM
- 不得将系统视为ERP
- 不得将系统视为OA
- 不得将系统视为普通知识库
