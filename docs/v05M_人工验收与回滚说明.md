# v0.5M 全站产品化收口、中文化清理、入口整合与核心流程重构

## 覆盖步骤
1. 解压补丁包到仓库根目录。
2. 覆盖 `app/`、`scripts/` 以及根目录 `verify_v05m_windows.bat`。
3. 不覆盖 `data/`、`logs/`、`.env`、`.venv/`。

## 迁移顺序
本补丁未新增数据表、未修改正式数据库结构，不需要新增迁移。
如目标环境尚未完成既有迁移，先运行：

```bat
migrate_all_windows.bat
```

## 验证顺序
```bat
verify_v05m_windows.bat
verify_all_windows.bat
```

也可直接运行：

```bat
.venv\Scripts\python.exe scripts\verify_v05m.py
.venv\Scripts\python.exe scripts\check_user_visible_english.py
```

## 启动方式
```bat
run_windows.bat
```

默认访问地址：

```text
http://127.0.0.1:8000
```

Worker 和 Scheduler 仍作为后台进程运行，不提供独立浏览器端口。

## 回滚方式
1. 停止 Web、Worker 和 Scheduler。
2. 用补丁覆盖前保留的文件备份恢复 `app/`、`scripts/` 和 `verify_v05m_windows.bat`。
3. 本补丁未运行数据库迁移；如管理员在部署前额外执行过迁移，请按原数据库备份策略恢复。

- `/`
