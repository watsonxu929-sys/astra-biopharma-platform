# 09 Changelog

## v0.4C-1

- 增加结构化 JSON 数据接入。
- 支持从现有原始情报/导入表读取数据。
- 自动建立导入批次和来源记录。
- 实现来源去重、候选去重和证据合并。
- 增加正式事实库、正式关系库和同步日志。
- 只有审核通过且定为事实的记录可同步。
- 推测、待判定和待确认关联不会提前进入正式库。
- 支持可选业务表映射，默认关闭。

## v0.4C

- 增加数据审核队列。
- 支持来源冲突、待确认关联和事实/推测分离。
- 支持单条审核与批量审核。
- 保留审核证据和操作历史。

## v0.4B

- 增加数据质量检查。
- 增加自动编号。
- 增加机构重复预警。
- 增加来源和人工确认状态。
- 增加删除保护与停用逻辑。

## v0.4A and Earlier

- 建立本地 FastAPI + SQLite 管理界面。
- 支持情报、主体、人物、项目、资源、事件、关系、行动等核心对象。
- 增加粘贴分析、导入导出、基础自检和早期数据模型。
