# P2.1 证据模型

`v04g_source_snapshots` 是唯一 EvidenceSnapshot。原始 URL、抓取时间、HTTP 状态、内容类型、原始 HTML/附件路径、内容哈希、标题、发布时间、元数据和状态均保存在快照行中。快照创建后，数据库触发器禁止修改 URL、原始内容、哈希和抓取时间；清洗与解析结果写入 RawIntelligence、处理块和候选，不覆盖原始证据。

候选证据关联保存 `snapshot_id`、引用片段、字符起止位置、页码、表格编号和通用定位 JSON。唯一约束阻止同一候选重复关联同一定位。正式产品同时关联获批候选和快照；删除产品时只级联删除关联行，不删除快照。

同一来源规范化 URL 的相同内容哈希复用快照；内容变化创建新快照并保留 `previous_snapshot_id`。附件只保存受控的相对路径和哈希，不在 API 中暴露本机绝对路径。
