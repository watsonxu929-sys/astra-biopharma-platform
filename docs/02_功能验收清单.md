# v0.4D-A 功能验收清单

## 1. 页面与路由

- [ ] `/review/structure/health` 返回 `ok: true`。
- [ ] `/review/structure` 可以正常打开。
- [ ] 首页顶部出现“情报结构化”。
- [ ] 原有 `/review` 和 `/review/intake` 仍能正常打开。

## 2. 来源进入工作台

- [ ] “原始情报库”中可以点击“开始结构化”。
- [ ] 同一条原始情报重复点击不会创建第二条来源记录或第二个任务。
- [ ] `needs_structuring` 来源可以建立任务。
- [ ] 原文、标题、来源链接和来源信息显示正确。

## 3. 草稿编辑

- [ ] 可以添加字段候选。
- [ ] 可以添加关系候选。
- [ ] 可以添加事件候选。
- [ ] 可以保存、修改、删除尚未送审的条目。
- [ ] 可以在左侧选择原文，并点击“使用当前选中文本作为证据”。
- [ ] 主体快速查找可以返回机构、人物、项目、事件或资源。
- [ ] 新主体可以保留 ID 为空，只填写主体名称。

## 4. 校验规则

- [ ] 没有任何条目时不能提交结构化复核。
- [ ] 没有证据摘录时不能提交复核。
- [ ] 字段候选缺少主体、字段名或候选值时不能提交。
- [ ] 关系候选缺少左右主体或关系类型时不能提交。
- [ ] 事件候选缺少事件名称或摘要时不能提交。

## 5. 内部结构化复核

- [ ] 草稿可以提交为“待结构化复核”。
- [ ] 待复核任务不能直接编辑。
- [ ] 可以填写原因后“退回修改”。
- [ ] 退回后恢复编辑能力。

## 6. 送入数据审核队列

- [ ] 只有“待结构化复核”任务可以送审。
- [ ] 字段候选进入 `/review`。
- [ ] 关系候选进入待确认关联。
- [ ] 事件候选拆分为事件名称、日期、类型、相关主体、摘要等可审计字段。
- [ ] 每条审核项都能看到原文证据摘录。
- [ ] 送审后成功条目锁定，不能直接改写。
- [ ] 重复点击送审不会再次生成重复候选。

## 7. 事实隔离

- [ ] 结构化完成后 `v04c1_canonical_facts` 不会直接新增正式事实。
- [ ] 字段和事件仍需在 `/review` 人工审核。
- [ ] 关系默认保持推测属性，人工确认后才能成为正式关联。
- [ ] 只有 v0.4C 审核通过且定为事实，再执行正式同步后才能进入事实库。

## 8. 原系统回归

- [ ] 首页正常。
- [ ] 情报、主体、人物、项目、资源、事件、关系、行动页面正常。
- [ ] 原始情报新增和详情页正常。
- [ ] v0.4C 自检通过。
- [ ] v0.4C-1 自检通过。
- [ ] v0.4D 自检通过。
