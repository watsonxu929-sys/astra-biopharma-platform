# v0.4D-A 手动替换步骤

## 一、阶段目标

v0.4D-A 用于把没有结构化字段的新闻、访谈、网页摘录和人工录入正文，整理为：

- 字段候选；
- 关系候选；
- 事件候选；
- 绑定原文证据的结构化草稿；
- 经内部复核后送入 v0.4C 数据审核队列。

本阶段不会绕过审核直接写入正式事实库。

## 二、替换前准备

1. 关闭当前后端窗口。
2. 确认项目根目录中存在：
   - `app`
   - `scripts`
   - `data`
   - `.venv`
3. 备份整个项目文件夹，或者至少保留 `data/app.db` 和当前源码。

迁移脚本还会自动创建数据库备份。

## 三、复制文件

把补丁包中的下列内容复制到项目根目录，同名文件夹选择“合并”：

```text
app/
  v04d_structuring.py
  templates/v04d_structuring.html
scripts/
  migrate_v04d.py
  verify_v04d.py
  seed_v04d_demo.py
migrate_v04d_windows.cmd
verify_v04d_windows.cmd
seed_v04d_demo_windows.cmd
docs/10_V04D_STRUCTURING.md
```

本补丁不会覆盖现有 `v04c_review.py`、`v04c1_ingestion.py` 和数据库。

## 四、修改主入口

按照：

```text
patches/main_py_必须追加.txt
```

修改 `app/main.py`，增加 v0.4D 路由 import 和 `include_router`。

## 五、增加公共导航

按照：

```text
patches/base_html_导航追加.txt
```

在 `app/templates/base.html` 增加“情报结构化”入口。

原始情报详情页按钮属于可选修改：

```text
patches/intelligence_detail_可选追加.txt
```

## 六、运行迁移

双击：

```text
migrate_v04d_windows.cmd
```

成功时应看到：

```text
[OK] v0.4D schema migration completed
[SAFE] Existing business tables and data were not deleted or rebuilt.
```

数据库备份保存在：

```text
data/backups/app_before_v04d_日期_时间.db
```

## 七、运行自检

双击：

```text
verify_v04d_windows.cmd
```

最后必须看到：

```text
ALL V0.4D CHECKS PASSED
[OK] Completed successfully.
```

自检使用临时数据库，不会向正式 `data/app.db` 写测试数据。

## 八、启动系统

运行原来的：

```text
run_windows.bat
```

依次打开：

```text
http://127.0.0.1:8000/review/structure/health
http://127.0.0.1:8000/review/structure
```

健康检查应显示：

```json
{
  "ok": true,
  "version": "0.4D-A"
}
```

## 九、演示数据

正式使用前可选择运行一次：

```text
seed_v04d_demo_windows.cmd
```

它会建立一条演示来源和一个包含字段、关系、事件草稿的结构化任务。

不要反复运行。脚本具备基本幂等保护，但演示数据仅用于功能验收。
