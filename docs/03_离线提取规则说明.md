# v0.4D-B 离线提取规则说明

## 定位

本阶段不是通用大语言模型，而是可审计、无需 API 密钥的离线预提取器。

核心方法：

- 正则表达式；
- 关键词；
- 句子边界；
- 上下文关联；
- 主体名称启发式识别；
- 已有主体库精确及包含匹配；
- 日期、临床阶段和项目代号标准化。

## 默认规则

系统首次迁移会建立：

1. 融资金额；
2. 融资轮次；
3. 临床阶段；
4. 员工人数；
5. 估值；
6. 成立时间。

另外内置代码逻辑支持：

- 人物与任职关系；
- 机构投资、合作、收购、授权关系；
- 融资、合作、获批、临床进展、并购、授权、处罚、任职事件；
- 英文数字药物或项目代号。

## 置信度

默认等级：

```text
高：>= 0.82
中：>= 0.62 且 < 0.82
低：< 0.62
```

分数只用于排序，不能代替人工审核。

加分因素示例：

- 候选值和触发词在同一句；
- 同句识别到明确主体；
- 同句识别到明确日期；
- 字段格式高度明确。

## 关系候选

关系方向容易受中文句式影响，因此关系默认进入推测或待确认流程。即使置信度较高，也不能直接成为正式关系。

## 规则修改

在 `/review/prestructure` 页面底部可以：

- 修改规则正则；
- 调整优先级；
- 调整基础置信度；
- 停用规则。

修改后点击“重新提取”才能生成新结果。已有候选和结构化草稿不会被静默修改。
