## 不可跳阶段原则

1. **必须按顺序推进**：每个阶段必须在前一阶段完成后才能开始
2. **阶段验收通过**：每个阶段必须通过验收才能进入下一阶段
3. **禁止跨越**：不得跳过任何阶段直接进入后续阶段
4. **阶段回退**：如果阶段验收失败，必须修复问题后重新验收

### 阶段验收结论

- **environment_invalid**：环境验证失败，需要重新准备环境
- **blocked**：存在阻塞问题，无法继续推进
- **conditional_pass**：条件通过，需要后续验证
- **pass_for_formal_migration**：通过，可进入正式迁移
