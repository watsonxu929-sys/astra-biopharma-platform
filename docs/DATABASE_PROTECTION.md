# 数据库保护规则

## 版本

PGF v2.0

## 引用

本规则为PGF v2.0治理框架的数据库保护规则，所有数据库操作必须遵守。

## 统一规定

所有数据库操作必须记录以下信息：

### 基本信息

| 字段 | 说明 |
|---|---|
| SHA | 文件SHA校验值 |
| 大小 | 文件大小（字节） |
| 修改时间 | 最后修改时间戳 |
| 是否DDL | 是否执行DDL操作（CREATE/DROP/ALTER） |
| 是否DML | 是否执行DML操作（INSERT/UPDATE/DELETE） |
| 是否Migration | 是否通过迁移脚本执行 |
| 是否新增数据 | 是否新增测试数据 |
| 是否正式库 | 是否为正式数据库（data/app.db） |

---

## 保护规则

### 正式库保护（data/app.db）

1. **禁止删除**：不执行DELETE语句删除正式业务数据
2. **禁止重建**：不执行DROP TABLE或重建表结构
3. **禁止清空**：不执行TRUNCATE或批量DELETE
4. **禁止修改主键**：不修改既有主键和业务编号
5. **禁止覆盖**：不自动覆盖正式主体字段

### 测试库保护（data/rehearsal/*.db）

1. **允许新增测试数据**：但必须使用唯一标识（如V06L-RECHECK-时间戳）
2. **允许迁移**：可执行迁移脚本
3. **允许重建**：测试库可重建，但需记录

### 操作前检查清单

- [ ] 确认操作的数据库路径
- [ ] 确认是否为正式库
- [ ] 确认操作类型（DDL/DML/Migration）
- [ ] 确认是否需要备份
- [ ] 确认是否有回滚方案

### 操作后验证清单

- [ ] 验证数据完整性
- [ ] 验证业务功能正常
- [ ] 记录操作日志
- [ ] 记录数据库状态（SHA、大小、修改时间）
