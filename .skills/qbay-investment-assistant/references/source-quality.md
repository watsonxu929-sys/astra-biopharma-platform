# 来源质量与引用规范

## 来源等级

### S级：强官方证据

- 企业官网和官方公众号原文；
- 政府官网；
- 交易所公告；
- 药监、临床登记、环评、工商等官方平台；
- 上市公司正式公告。

### A级：高可信机构来源

- 投资机构官网；
- 行业协会；
- 权威数据库；
- 企业正式招聘页面；
- 高校、医院和科研机构官网。

### B级：权威媒体

- 权威财经媒体；
- 权威产业媒体；
- 有明确记者、日期和原始出处的报道。

### C级：辅助来源

- 招聘平台；
- 行业自媒体；
- 转载；
- 无法确认原始出处的二手信息。

## 冲突处理

- S/A级优先于B/C级，但不能无条件覆盖；
- 来源时间更近不代表必然正确；
- 冲突结论并列展示；
- 无法消解时标记“待核实”；
- 不使用单一C级来源支撑A/B级招商结论。

## 引用字段

每条重要事实记录：

- title
- url
- published_at
- captured_at
- source_level
- excerpt
- supports

摘录保持简短，不复制大段版权内容。
