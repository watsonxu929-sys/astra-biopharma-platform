# 地域分类规则

## 分类

1. **上海本地型**：注册地或主要经营地在上海，且非Q-BAY在孵、非钱塘区企业。
2. **浙江省内型**：注册地或主要经营地在浙江省内但非钱塘区。
3. **长三角其他地区型**：江苏、安徽及其他明确长三角地区，非上海、非浙江。
4. **长三角外异地型**：长三角以外地区。
5. **钱塘/Q-BAY本地资源型**：钱塘区企业、Q-BAY在孵企业或已深度纳入本地合作网络。

## 使用规则

- 地域分类描述的是招商路径，不代表企业价值。
- 本地资源型使用 `R`，不使用A/B/C/D。
- 主要经营地与注册地不一致时，分别记录，并以实际决策中心判断招商难度。
- 长三角其他地区型通常比长三角外异地型更容易建立区域协同，但不自动提高等级。
- 已明确在上海或浙江有分支机构时，记录为已有区域基础，但仍需判断是否存在新增布局需求。
