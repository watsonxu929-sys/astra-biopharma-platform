# 与产业情报系统的数据映射

| 研判结果 | 系统对象 | 写入原则 |
|---|---|---|
| 企业事实 | Organization | 仅生成更新建议，人工批准后写入 |
| 关键人物 | Person | 同名不自动合并 |
| 融资/合作/扩产/临床 | Event | 事件需证据和主体确认 |
| 招商信号 | Signal | 可先生成候选信号 |
| 招商等级 | LeadRecord或招商评估记录 | 保存分项得分和校正理由 |
| 关系线索 | RelationshipCandidate | 不自动建立正式关系 |
| 行动建议 | Recommendation | 人工确认后转Action |
| 正式跟进 | Action | 必须有负责人、期限和依据 |
| 来源 | SourceRecord / Snapshot | 保留URL、时间、摘录和来源等级 |
| 关注对象 | WatchlistItem | 加入不自动生成行动 |

## 写入安全

- 不自动覆盖正式主体字段；
- 不自动合并同名主体；
- 不自动建立正式关系；
- 不自动创建行动；
- 所有判断保留证据、来源和人工审核状态。
